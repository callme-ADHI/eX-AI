🧪 eX-AI Autofill Test Harness

Legitimate test ground for the eX-AI QA Autofill extension. Verify scanner accuracy, filler safety, and submission guards across various DOM frameworks.

Safety Verification: Every test page has submit and navigation event listeners that record any trigger in window.__submitted and window.__next. The extension must never trigger them.

1. Native Form Controls (native.html)

Tests fieldset/legend grouping, native radio inputs, multi-answer checkboxes, text input, textarea, and select dropdowns.

2. ARIA Semantic Controls (aria.html)

Custom component libraries using role="radiogroup", role="radio", role="listbox", and role="option" with aria-checked and aria-selected.

3. Heuristic / Custom Options (custom.html)

Plain divs styled as clickable options (div.option), button options, and a demonstration of the auto-advancing option click limitation.

4. React Controlled Inputs (react.html)

React 18 state-controlled inputs, radios, select, and textarea. Verifies that setNativeValue triggers React synthetic event state synchronization.

5. Code Editors Integration (editors.html)

Monaco, CodeMirror 5, CodeMirror 6, Ace Editor, plain textarea, contenteditable, and programming language select dropdown.

6. Complete Exam Flow (exam-flow.html)

Combined test flow: 3 MCQs, 1 coding editor question with language dropdown, Next button, and Submit attempt button.
